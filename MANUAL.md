# Kid Sudoku: User Manual

## 1. Put it on the phone (one time)

You need internet for this step only.

**iPhone / iPad**
1. Open **Safari** (it must be Safari) and go to **https://kurobuilds.github.io/sudoku/**
2. Tap the **Share** button (square with an arrow pointing up).
3. Scroll down and tap **Add to Home Screen**, then **Add**.

**Android**
1. Open **Chrome** and go to **https://kurobuilds.github.io/sudoku/**
2. Tap the **⋮** menu (top right).
3. Tap **Add to Home screen** or **Install app**, then **Install / Add**.

A colourful **Sudoku** icon appears on the home screen. Tap it to play.
From now on it works **without internet**, even in airplane mode.

**On a computer:** just open the link in any browser. In Chrome or Edge you can
also click the install icon in the address bar to get it as an app.

## 2. How to play

Fill every empty square so that **each row, each column and each thick-bordered
box** has every number exactly once, with no repeats.

| Size | Numbers used | Good for |
|---|---|---|
| 4×4 Mini | 1–4 | First-timers, younger kids |
| 6×6 Junior | 1–6 | Once 4×4 feels easy |
| 9×9 Classic | 1–9 | The real thing |

Pick a size and a level (😊 Easy, 🤔 Medium, 😎 Hard) at the top. Changing either
one starts a new puzzle.

**To fill a square:** tap the square, then tap a number at the bottom.

## 3. The screen

| Thing | What it means |
|---|---|
| ⏱ timer | How long this puzzle has taken. Pauses when the app isn't on screen |
| ❤️❤️❤️ hearts | Each wrong number costs a heart. Lose all 3 and the puzzle ends |
| 💡 3 | Hints left for this puzzle |
| Yellow square | The square you picked |
| Light-yellow squares | Its row, column and box: where the same number can't go again |
| Blue squares | Other squares with the same number as the one you picked |
| Red number | That number is wrong. Erase it or pick another |
| Dark numbers | Part of the puzzle, can't be changed |
| "3 left" under a number button | How many of that number still need placing. Shows ✓ when done |

## 4. The buttons

| Button | What it does |
|---|---|
| ↩️ **Undo** | Takes back the last move |
| 🧽 **Erase** | Clears the picked square |
| ✏️ **Notes** | Pencil mode: numbers go in small as "maybe" guesses. Tap again to turn off. Notes never cost hearts |
| 💡 **Hint** | Fills in the right answer for the picked square (or a random one if none is picked) |
| ✨ **New Puzzle** | Starts a fresh puzzle at the same size and level |

Finish a puzzle to earn up to ⭐⭐⭐: one star for every heart you still have.

**Keyboard (computer):** number keys to fill, arrows to move, Backspace to erase,
**N** for notes, **Ctrl+Z** to undo.

## 5. Tips for grown-ups

- Start on **4×4 Easy**. Move up when they finish with 3 stars a few times in a row.
- Teach the "what's missing?" trick: look at a row, see which number isn't there yet.
- Notes are great for 9×9: write the possible numbers small, then cross them off.
- Each phone keeps its own progress. Nothing is shared or sent anywhere.

## 6. Troubleshooting

| Problem | Fix |
|---|---|
| No "Add to Home Screen" on iPhone | You must use **Safari**, not Chrome or an in-app browser (WhatsApp, Messenger). Copy the link into Safari. |
| Doesn't open offline | Open it once with internet and wait a few seconds so it can save itself, then try again. |
| Want the newest version | Open the app once while on internet, close it fully, and open it again. |
| Puzzle feels stuck | Use a 💡 hint, or ✨ New Puzzle. Every puzzle has exactly one answer, so it's always solvable. |
| Lost progress | Clearing browser data / history removes the saved puzzle. Just start a new one. |
